# Pocket Studio

아이폰 홈 화면에서 여는 스텝 시퀀서. 칸을 눌러 음을 찍고, 이펙트를 걸고, wav 파일로 뽑는다.

앱스토어도 Xcode도 개발자 계정도 필요 없다 — 사파리로 열어 "홈 화면에 추가"하면 끝이다.

**주소**: (Pages 배포 후 채운다)

## 뭘 할 수 있나

- **16스텝 격자** — 세로는 트랙(악기), 가로는 시간. 칸을 누르면 그 자리에서 소리가 난다.
- **악기 9종** — 킥/스네어/하이햇/클랩/톰(드럼), 베이스/리드/플럭/패드(신스). 전부 코드로 합성한다.
  샘플 파일이 하나도 없어서 저장소가 가볍고 비행기 모드에서도 똑같이 소리 난다.
- **이펙트** — 트랙마다 드라이브·필터·레조넌스·코러스, 그리고 에코와 리버브를 얼마나 보낼지.
  에코 간격은 BPM에 맞춰 1/16 ~ 1/2 중에 고른다.
- **패턴 A~D** 를 만들어 곡 구성에 늘어놓으면 곡이 된다 (A A B A 식).
- **wav 내보내기** — 44.1kHz 16비트 스테레오. 공유 시트에서 "파일에 저장"으로 원하는 폴더에 넣는다.

## 쓰는 법

칸을 누르는 방식이 트랙 종류에 따라 다르다.

| 트랙 | 누르면 |
|---|---|
| 드럼 | 꺼짐 → 보통 → **세게** → 꺼짐 으로 돈다. 하이햇은 세게 치면 오픈 햇이 된다. |
| 신스 | 위 "음" 줄에서 고른 음이 찍힌다. 같은 음을 다시 누르면 지워진다. |

음 번호는 **스케일 안에서의 순번**이다. 단5음이면 1~5. 스케일 밖 음은 아예 못 찍게 해뒀기
때문에 아무 칸이나 눌러도 불협이 안 난다 — 이게 이 앱의 핵심 설계다.

칸 아래쪽 흰 줄은 한 옥타브 위, 위쪽 검은 줄은 한 옥타브 아래다.

## 저장

**자동 저장이 없다.** 앱을 닫으면 찍은 패턴은 사라진다. 마음에 드는 게 나오면 그때그때
`내보내기` → `파일로 저장` 으로 wav 를 뽑아 둔다.

프로젝트 파일(.json)로 저장해 나중에 이어서 편집하는 기능은 일부러 넣지 않았다.
필요해지면 그때 붙인다.

## 구조

```
index.html   화면 전체
app.css      스타일
app.js       상태 + 화면 그리기 + 입력 처리
music.js     음계·타이밍 계산 — 순수 함수만, DOM 도 오디오도 안 건드림
audio.js     소리 합성 + 믹서 + 재생/렌더링 엔진
wav.js       AudioBuffer → .wav 바이트
sw.js        서비스 워커 (오프라인)
test/        node 로 도는 단위 테스트
```

## 검증

```sh
node test/run.js
```

`./serve.sh` 로 로컬 확인 (http://127.0.0.1:8080).
서비스 워커는 HTTPS 에서만 등록되므로 **오프라인 동작은 Pages 주소에서 확인해야 한다.**
