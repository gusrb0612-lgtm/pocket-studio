# 기획 메모

폰에서 며칠 써 본 뒤 채운다. 지금은 결정 이유만 남긴다.

## 왜 PWA 인가

gym-log 와 같은 이유. Xcode 설치, 애플 개발자 계정, 7일마다 재서명이 전부 사라진다.
대가로 포기한 것: 오디오유닛/AUv3, 백그라운드 오디오, 다른 음악 앱과의 연동(Ableton Link 등).
나중에 이게 아쉬워지면 네이티브를 재검토한다.

## 왜 스텝 그리드인가 (피아노롤 아님)

폰 화면에서 피아노롤은 세로로 음높이를 다 펼쳐야 해서 확대·스크롤이 필수가 된다.
손가락으로 찍는 데는 격자가 맞다. 대신 멜로디 자유도를 잃는 걸 **스케일 제한**으로 메꿨다 —
스케일 밖 음을 아예 못 찍게 해서, 자유도가 낮은 대신 틀린 음도 안 나온다.

## 안 넣은 것

- **프로젝트 저장(.json) / 자동 저장** — 사용자가 wav 내보내기만 고름. 필요해지면 붙인다.
- **녹음(마이크 입력)** — 샘플이 들어오는 순간 저장소·저작권·용량 문제가 전부 따라온다.
- **마디 길이 32/64** — 16스텝 패턴을 곡 구성으로 이어붙이는 쪽이 화면에 맞다.
